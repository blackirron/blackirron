## What I'm Working On

Every project here started with one question: **why does this work the way it does?**
Not how to use it — why it was designed this way, what tradeoffs were made, what would happen if you stripped it down and rebuilt it differently.

That question has taken me from application code all the way down to the Linux kernel.

---

## Projects

### 🔧 Minimal Container Runtime
> *Re-implementing Docker's core ideas from first principles*

Built a minimal container runtime using **Linux namespaces**, **cgroups v2**, and a minimal filesystem layer — no wrappers, no shortcuts. The goal wasn't to compete with Docker. It was to understand what containerization actually *is* at the OS level, and why the abstractions we use daily were designed the way they were.

`C` `Linux` `namespaces` `cgroups v2` `systems programming`

---

### 🧠 Handwritten Notes → Digital Text (AI Agent)
> *Not just OCR — context-aware transcription*

Building an AI agent for converting handwritten notes into accurate digital text. Uses linguistic structure to resolve ambiguity the way a human reader would — not just pattern matching. Direction: AI that understands context, not just pixels.

`Python` `ML` `NLP` `OCR` `agents`

---

### 🌐 Chrome Scroll Extension
> *Real UX friction, fixed*

A Chrome extension for smoother scrolling UX across sites. Came from actual annoyance. Built the fix.

`JavaScript` `Chrome Extension API` `browser tooling`

---

### 🔒 WhatsApp Media Tool
> *Privacy controls the default app doesn't give you*

Local control over what gets saved, what gets shared. Built around privacy as the primary design constraint.

`Python` `privacy` `automation`

---

### 🍽️ Restaurant Management System
> *Full end-to-end, built in school*

Orders, inventory, billing — Python and SQL. Built because nothing available did exactly what was needed.

`Python` `SQL` `full-stack`
